Script samples for:
- converting pdf files to images (main.py#convert_pages, requires additional setup on Windows, see comments) 
- performing ocr for printed characters on the images (main.py#ocr, requires additional setup on Windows, see comments)
- evaluating checkboxes based on pixel colour (area_grabbing.py and survey_templates.py)
- OCR for handwriting for images with a single line of text (htr.py)
